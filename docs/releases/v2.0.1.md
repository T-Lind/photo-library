# photolib 2.0.1 — clean shutdown and reliable photo navigation

Photolib 2.0.1 is a focused Windows patch release addressing the two issues
reported after 2.0.0: the local server now exits with the desktop app, and the
photo viewer now visibly changes photos when using its arrows.

## Download

Download **`photolib-2.0.1-windows-x64-setup.exe`** below. Close Photolib
before running setup. The upgrade preserves your indexed library, names,
albums, thumbnails, settings, and original photos.

Because the app is not code-signed yet, Microsoft Defender SmartScreen may
show a warning. If you downloaded the file from this GitHub release, choose
**More info**, then **Run anyway**.

## Fixed

- **Server cleanup on exit:** closing the Photolib window now explicitly stops
  its bundled `photolib-server` process. Reopening and closing the app no longer
  accumulates background server processes in Task Manager.
- **Photo viewer navigation:** clicking the previous/next buttons or pressing
  Left/Right now replaces the displayed photo instead of advancing only the
  viewer metadata while leaving the old image on screen.

## Verification

- Two consecutive Windows open/close cycles left zero `photolib-server`
  processes behind.
- Previous, next, Right, and Left navigation were exercised against the real UI
  and changed the displayed image each time.
- The bundled model self-check, archive integrity test, installer payload
  inspection, and complete automated test suite passed.

## Privacy and system notes

Photos remain on your computer. Search, indexing, thumbnails, and the bundled
SigLIP 2 model run locally. Face recognition remains an optional one-time model
download initiated from inside the app.

- Windows 10/11, x64
- About 5 GB of free disk space recommended during setup
- A GPU is optional
- Current release asset: Windows x64 only
