# photolib 2.0.0 — private search for your photo library

Photolib 2.0.0 is the first packaged Windows release: a complete local photo
library with natural-language search, face recognition, people management,
albums, and duplicate review in a standalone desktop app.

## Download

Download **`photolib-2.0.0-windows-x64-setup.exe`** below. It contains the
desktop app, local server, and offline SigLIP 2 search model; Python and
Node.js are not required.

Before installing or updating, close any running Photolib window. The setup
now checks for a running copy before replacing files, installs for the current
Windows user, and creates a Start menu shortcut. Existing library data is
preserved.

Because this first build is not code-signed, Microsoft Defender SmartScreen
may show a warning. If you downloaded the file from this GitHub release,
choose **More info**, then **Run anyway**.

## Highlights

- Search photos with ordinary descriptions such as “kids at the beach at sunset.”
- Browse dedicated **Photos**, **People**, **Albums**, and **Library** tabs.
- Detect and group faces locally, then name, merge, split, or correct people.
- Build albums manually or from smart suggestions.
- Filter by person, folder, date, place, and media type.
- Find exact and visually similar duplicates before moving unwanted copies to
  the Recycle Bin.
- Index incrementally, so later scans process only new and changed files.
- Keep originals in place: Photolib never moves, modifies, or uploads them.

## Privacy and models

Image search, indexing, thumbnails, and the app itself run locally. The
packaged SigLIP 2 model works offline from first launch. Face recognition is
optional; when you explicitly enable it, Photolib downloads the InsightFace
weights once (about 290 MB) and then runs them locally. Review the InsightFace
license notice shown in the app before enabling that download.

## System notes

- Windows 10/11, x64
- About 5 GB of free disk space recommended during setup (temporary extraction
  plus the installed app)
- A GPU is optional; indexing works on CPU
- Current release asset: Windows x64 only
