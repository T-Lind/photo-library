# photolib 2.0.2 — smaller packaging, faster indexing, resilient desktop

Photolib 2.0.2 improves the Windows release pipeline and makes both indexing
and the native desktop lifecycle more efficient and reliable.

## Download

Download **`photolib_2.0.2_x64-setup.exe`** below. Close Photolib before
running setup. The upgrade preserves your indexed library, names, albums,
thumbnails, settings, and original photos.

The installer is not code-signed yet, so Microsoft Defender SmartScreen may
show a warning. If you downloaded it from this GitHub release, choose
**More info**, then **Run anyway**.

## Highlights

- **One Windows installer:** Windows now uses a single Tauri/NSIS setup
  executable. Obsolete portable/SFX packaging has been removed.
- **Smaller offline model:** the standard package uses a quality-gated hybrid
  INT8 SigLIP 2 export. Sensitive vision layers remain FP32, while the bundled
  model is about 45% smaller than the full FP32 profile.
- **Quality is enforced:** the frozen release binary reproduces the reference
  model with 0.993803 text cosine and 0.997860 image cosine.
- **Reliable desktop lifecycle:** a second launch focuses the existing window;
  normal exits drain the local server gracefully; an unexpected server crash
  is restarted once.
- **Less indexing work:** perceptual hashing and thumbnail pregeneration reuse
  the image buffer already decoded for embeddings and face detection.
- **Safer release builds:** CI selects one model profile, verifies the packaged
  graphs, cleans stale staging, and rejects Windows installers above 900 MiB.

## Verification

- 248 Python tests passed.
- Rust formatting and offline compilation passed.
- The frozen executable passed tokenizer, text, image, and face-runtime checks.
- The Windows NSIS installer was built from a clean 1,558.7 MiB staged payload.
- Final installer size: 837.5 MiB.

## Privacy and system notes

Photos remain on your computer. Search, indexing, thumbnails, and the bundled
SigLIP 2 model run locally. Face recognition remains an optional one-time model
download initiated from inside the app.

- Windows 10/11, x64
- About 4 GB of free disk space recommended during setup
- A GPU is optional
- Current release asset: Windows x64 only

For a silent current-user installation, run:

```powershell
photolib_2.0.2_x64-setup.exe /S
```
